定義 Definition

氣喘是一種異質性疾病，通常以慢性氣道發炎為特徵。以呼吸道症狀病史（喘鳴 wheeze、呼吸短促、胸悶、咳嗽）及可變呼氣氣流受限來定義，症狀與氣流受限程度隨時間變化。

要點：氣流受限後期可能變為固定性（persistent）。氣道過度反應與氣道發炎雖常見，但非診斷之必要或充分條件。

診斷流程 Figure 1

  1. 慢性或反覆呼吸道症狀的病人 → 症狀、病史與理學檢查是否典型？否 → 進一步檢查其他診斷
  2. 是 → 有無肺量計或 PEF？沒有 → 考慮生物標記 → 若其他診斷不太可能，經驗性給予含 ICS 治療
  3. 有 → 做支氣管擴張劑前後肺功能 → 是否證實可變呼氣氣流受限？
  4. 是 → 以含 ICS 治療；否 → 症狀發作期間重測或加做其他檢查
  5. 經驗性治療者：1–3 個月後複評（含 PEF 或肺量計）。症狀與肺功能改善 → 依氣喘治療；未改善 → 轉診上級評估
Test before treating：在開始含 ICS 治療之前先確認診斷，一旦控制改善再回頭確診會困難得多。若病人以嚴重未控制的呼吸道症狀／徵象表現，先當作急性發作處理。

支持氣喘的症狀特徵 Table 1.1

典型症狀：喘鳴、呼吸短促、胸悶、咳嗽。

  • 症狀的頻率與強度會變化
  • 常在夜間或起床時發生或加重
  • 常由運動、大笑、過敏原、冷空氣誘發
  • 用力後症狀加重（極具特異性）
  • 常在病毒性呼吸道感染時發生或加重

降低氣喘可能性的線索

  • 單獨慢性咳嗽、無其他呼吸道症狀
  • 慢性大量痰液
  • 呼吸困難合併頭暈、頭重腳輕、周邊針刺感
  • 運動時胸痛
  • 吸氣性喘鳴（stridor）→ 考慮上呼吸道／聲帶功能異常
急性呼吸困難的其他原因：氣胸、過敏性休克、可誘發性喉阻塞、肺炎、急性心臟衰竭、肺栓塞、異物吸入。

Type 2 生物標記在診斷的角色

在有典型氣喘症狀、但肺量計／PEF 無法取得或結果陰性的病人：

  • FeNO：成人／青少年 > 50 ppb；兒童 > 35 ppb
  • 血液嗜酸性球：高於當地／區域參考範圍

可支持 Type 2 氣喘診斷，但也可能來自非氣喘疾病。

低值不能排除氣喘。FeNO 與嗜酸性球會隨性別、年齡、儀器與採檢地點大幅變動；嗜酸性球早晨較高，FeNO 清晨較低。

兒童 ≤5 歲的診斷 完整報告

此年齡層無法可靠執行肺功能，屬臨床診斷，依三要件：

  1. 反覆的喘鳴／咳嗽發作，尤其非僅出現於病毒感染時
  2. 排除其他診斷
  3. 對氣喘藥物的治療反應：試驗性低劑量 ICS 2–3 個月改善、停藥後惡化

鑑別診斷：反覆病毒感染、胃食道逆流、異物吸入、氣管／支氣管軟化、囊性纖維化、原發性纖毛運動障礙、先天心臟病、支氣管肺發育不良、免疫缺損、結核、血管環壓迫。

B.1 急性發作的風險因子 Table 2B.1

症狀未控制本身就是重要風險因子。下列因子即使症狀很少也會增加發作風險：

  • SABA 過度使用（每年 ≥3 支 200 劑裝）— 也增加氣喘死亡風險，尤其每月 ≥1 支時
  • ICS 不足：未使用 ICS、順從性差、吸入技巧錯誤
  • 共病：肥胖、慢性鼻竇炎、胃食道逆流、確診的食物過敏，或懷孕
  • 暴露：已致敏的過敏原、抽菸、電子菸、空氣污染
  • 重大心理或社會經濟問題
  • 肺功能差（尤其 FEV₁ <60% 預測值）、支氣管擴張劑反應幅度大
  • Type 2 發炎指標：血液嗜酸性球偏高、FeNO 偏高
  • 過去一年曾嚴重發作，或終生曾因氣喘插管／進加護病房

B.2 發展成固定性氣流受限的風險

  • 早產、低出生體重、嬰兒期體重快速增加、頻繁有痰咳嗽
  • 有嚴重發作病史卻未使用 ICS
  • 暴露於菸害或有害化學物質
  • 診斷時 FEV₁ 偏低
  • 痰液或血液嗜酸性球偏高

B.3 藥物副作用的風險

  • 全身性：頻繁使用口服類固醇、長期高劑量／高效價 ICS、P450 抑制劑（ritonavir、ketoconazole、itraconazole）
  • 局部性：高劑量／高效價 ICS、吸入技巧不佳

    其他治療選項

    • 特定過敏原免疫療法（SLIT）：成人／青少年有塵蟎過敏且含 ICS 治療下控制不佳者可考慮加用舌下免疫療法。FEV₁ ≤70% 預測值者不可使用
    • LTRA（montelukast、pranlukast、zafirlukast、zileuton）：效果不如每日 ICS，預防急性發作方面尤其較差。Montelukast 與嚴重精神健康影響有關
    • 兒童 6–11 歲 Step 1–3：對有臨床相關致敏、控制不佳但穩定者，可考慮加成過敏原免疫療法

    不建議的治療 Non-recommended

    • 維持性口服類固醇——僅限最後手段
    • 口服 salbutamol、口服茶鹼、口服 epinephrine、吸入 fenoterol——不良反應風險增加
    • 規律使用 SABA——1–2 週內即增加氣道過度反應與氣道發炎，並降低支氣管擴張反應
    使用非 formoterol 的 LABA 做每日 ICS-LABA 維持治療的病人，不可用 ICS-formoterol 當緩解劑，應改用 SABA 或 ICS-SABA。

    兒童：prednisolone 1–2 mg/kg/day（上限 40 mg）每天早上 × 3–5 天
    使用少於 2 週時，停藥前不需減量。
    不要做／不要給：不常規做胸部 X 光或血液氣體分析、不常規開抗生素、不使用鎮靜劑。
    pMDI + spacer 的正確給法：Salbutamol 每 puff 100 mcg；ipratropium 每 puff 20 mcg。用 spacer 一次只按一下，太喘無法單次深吸後閉氣者改用潮氣呼吸。Salbutamol 每次按壓前都要搖勻。呼吸道感染或高度懷疑感染的病人避免使用霧化器。
    在 FEV₁ >30% 預測值的急診病人研究中，高劑量 budesonide-formoterol 的效果與安全性與高劑量 salbutamol 相當。

    1 小時內（或更早）複評

    • 評估血氧飽和度、呼吸速率、輔助肌使用、進氣量、PEF；<18 歲重測 PRAM
    • 必要時再給支氣管擴張劑並評估反應
    • 惡化或未改善 → 轉送更高層級照護
    • 是否住院依：臨床狀態、症狀與肺功能、治療反應、近期與過去發作史、在家自我處理能力

    可返家的條件

    • 症狀與徵象改善，且最後一次 salbutamol 後 1–2 小時內符合「輕度」標準
    • 空氣下 SpO₂ ≥92%
    • PEF 改善且 >70% 個人最佳值或預測值
    • 家中有足夠的照護資源

    出院前必做

    • 記錄診斷（若已確診）
    • 開始或增加含 ICS 的治療以降低再次發作風險——≥12 歲優先使用 ICS-formoterol MART
    • 緩解劑改為需要時使用，不是規律使用
    • 訓練吸入技巧（pMDI 要用 spacer），並強化順從性
    • 若已開始口服類固醇，依療程繼續服完
    • 安排追蹤：成人 2–7 天內；兒童 2–5 天內
    • 確認有足夠的藥物到回診為止

    追蹤時要做

    • 發作是否已緩解？若否，口服類固醇是否要繼續，或需轉急診？
    • 確認病人持續使用含 ICS 治療；≥12 歲若尚未使用 ICS-formoterol，宜改為 MART
    • 確認緩解劑為需要時使用而非規律使用
    • 檢查並矯正吸入技巧與順從性
    • 檢查並處理可調整的風險因子
    • 行動計畫：病人是否理解？是否需要修改？
    • 過去一年若已使用超過 1 個療程口服類固醇 → 轉診專科
    • 安排 2–3 個月內的下次回診

    書面氣喘行動計畫 Written asthma action plan

    所有病人都應有書面、數位或圖示式的行動計畫（不能只是口頭交代）。內容須包含：平時的治療、氣喘惡化時要做什麼改變、何時就醫。

    目前的緩解劑惡化時如何自我處置何時就醫
    低劑量 ICS-formoterol

    行動計畫中可考慮開始口服類固醇的情況：

    • 用了更多緩解劑，症狀仍在 2–3 天內持續惡化
    • 症狀快速惡化
    • 肺功能低下：FEV₁ <60% 預測值或 PEF <60% 個人最佳值
    • 病人有突發嚴重發作病史且症狀正在惡化
    若病人手上有備用的口服類固醇處方，應告知盡可能在服用前先聯絡醫師。並衛教常見副作用：睡眠障礙、食慾增加、胃食道逆流、情緒變化。
    口服類固醇在嚴重發作時可救命，但每一個療程都會累積副作用風險——透過優化吸入治療（注意技巧與順從性）、以及改用 Track 1 的 ICS-formoterol，可以減少療程需求。

    GINA 2026 更新重點與參考資料
    本工具內容已與 GINA 2026 Summary Guide（2026 年 7 月版）逐項核對。

    診斷

    • 診斷流程圖（Figure 1）簡化
    • 指出 ERS/ATS 2022 的支氣管擴張劑反應標準（>10% predicted）可能造成低診斷；GINA 維持 ≥12% 且 ≥200 mL
    • Table 1 明確以 成人 ≥18 歲 / 兒童 6–17 歲分界（與治療階梯的 12 歲分界不同）

    評估工具 新

    • CAAT（Chronic Airways Assessment Test）：8 題，成人
    • Peds-AIRQ：5–11 歲，合併症狀與發作風險
    • PRAM：<18 歲急性發作嚴重度評分

    治療

    • Track 2 Step 1 改為 AIR-only：需要時低劑量 ICS+SABA（複方或分開吸入器）。BATURA 研究顯示相較單用 SABA，嚴重發作風險減少近一半
    • 兒童 6–11 歲 Step 1 改為 AIR-only：需要時低劑量 ICS-formoterol 或需要時低劑量 ICS+SABA（CARE 研究）
    • Step 5 LAMA 證據更新，新增三合一 budesonide-formoterol-glycopyrronium（≥12 歲）
    • 新生物製劑：depemokimab（anti-IL5，≥12 歲）、生物相似藥 omalizumab-igec

    急性發作

    • 新流程圖，嚴重度統一為輕度／中度／重度或危及生命，並列出各級的明確判準
    • ICS-formoterol 新增為輕度發作的處置選項（budesonide-formoterol 160/4.5 2 puffs）
    • SABA 劑量分級明確化（輕 4 / 中 4–6 / 重 6–10 puffs）
    • <18 歲強烈建議使用 PRAM 評分

    非藥物處置與特殊族群

    • 戒菸／避免二手菸；肺復健、體能活動、減重
    • 疫苗：肺炎鏈球菌、百日咳、COVID-19、流感、RSV，依當地年齡層建議
    • 職業性氣喘：早期辨識、完全移除暴露
    • 懷孕、高齡、食物過敏與過敏性休克、手術：各有專節考量
    • 控制良好的氣喘病人罹患重症 COVID-19 或相關死亡的風險不高於一般人；但近期需要口服類固醇或因嚴重氣喘住院者風險較高
    • 呼吸道病毒流行期間：繼續使用 ICS，確保每人都有書面行動計畫
    • 感染或疑似感染者避免用霧化器，改用 pMDI + spacer；確診／疑似 COVID-19 者避免做肺量計
    • 開立 COVID-19 抗病毒藥前，查核與氣喘用藥的交互作用
